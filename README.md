# video-converter-tool

A Python GUI wrapper for ffmpeg to help with conversions.

For now, the relevant ffmpeg binaries must be downloaded from the [official FFMPEG website](https://www.ffmpeg.org/download.html) for your operating system, and the binaries and dll files (`ffmpeg`, `ffplay`, etc) must be placed inside the `ffmpeg`directory.
